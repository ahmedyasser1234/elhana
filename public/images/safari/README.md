# 📁 هيكل مجلدات الصور والفيديوهات — Media Folder Structure

## كيف يعمل النظام؟

**أضف أي صورة أو فيديو في المجلد الصحيح → تظهر فوراً في الموقع تلقائياً**

لا يلزم تغيير أي كود. فقط ضع الملف في المجلد المناسب وأعد تشغيل السيرفر (npm run dev).

## قواعد تسمية الملفات (اختيارية)

إذا أضفت الصور مباشرة في المجلد الرئيسي بدون مجلدات فرعية (مثل single/)، ستظهر في **جميع المواعيد الأربعة**.

يمكنك أيضاً تسمية الصورة باسم يحتوي على الكلمة لتصنيفها تلقائياً:
- يحتوي على `sunrise` → شروق
- يحتوي على `morning` أو `9am` → صباح
- يحتوي على `sunset` أو `maghrib` → غروب
- يحتوي على `dinner` أو `night` → عشاء
