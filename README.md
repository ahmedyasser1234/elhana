# elhana - El Hana Group (مجموعة الهنا للرحلات والمغامرات)

موقع وتطبيق حجز الرحلات والأنشطة السياحية في شرم الشيخ وجنوب سيناء (رحلات بحرية، سفاري، سانت كاترين، دهب، طابا، ونويبع).

## مميزات المشروع
- **واجهة مستخدم متطورة (UI/UX):** بتصميم جذاب، تفاعلي بالكامل مع دعم اللغتين العربية والإنجليزية و PWA.
- **لوحة تحكم إدارية شاملة:**
  - إدارة الحجوزات والتنبيهات المباشرة (واتساب، جيميل، تليجرام).
  - إدارة المرشدين السياحيين ونظام تقييمات سري للأدمن عبر QR Code لكل مرشد ولكل رحلة.
  - تعديل فوري لأسعار الرحلات في كل أنحاء الموقع بدون باك إند (Client-Side State).
  - استبدال ورفع صور الرحلات مباشرة وتخزينها في التخزين المحلي للمتصفح.
  - إدارة فريق الإدارة والمشرفين (الأدمن الرئيسي: ahmedyasser697@gmail.com والمشرفين).

## التقنيات المستخدمة
- React 19 + Vite
- Tailwind CSS
- Lucide React Icons
- i18next (Arabic / English)
- Vite PWA Plugin
